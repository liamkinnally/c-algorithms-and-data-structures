# C Data Structures

C implementations of fundamental data structures and algorithms developed through coursework and programming practice.

## Implementations

- **Linked List Operations** — doubly linked list manipulation and node insertion/removal
- **Balanced Indexed Deque** — dual-deque structure supporting efficient front, back, middle insertion, and indexed access
- **Grid Region Connectivity** — breadth-first search and flood fill for connected-region queries
- **Scoped Symbol Table** — binary search tree with scoped declarations, symbol lookup, and dynamic memory management
- **Pair Threshold Binary Search** — binary search over a threshold with pair-validation logic

## Concepts

C, pointers, dynamic memory allocation, linked lists, queues, deques, binary search trees, breadth-first search, binary search, and algorithm design.
